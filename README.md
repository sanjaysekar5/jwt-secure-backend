# JWT Secure Java Spring Boot Backend 🔒

A secure REST API boilerplate showcasing JWT (JSON Web Token) authentication using Spring Boot 3.x and Spring Security.

## Tech Stack
- Java 17
- Spring Boot 3.1.5
- Spring Security
- JSON Web Token (JJWT)

## API Endpoints
- `GET /api/public` - Public resources
- `GET /api/secure` - Guarded resource (Requires valid Bearer token)
